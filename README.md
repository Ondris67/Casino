# 🎰 Royal Chips Casino

Casino hra o **virtuální žetony** běžící celá v prohlížeči – bez serveru, bez instalace.
Žetony nemají žádnou reálnou hodnotu a nelze je vyplatit. Pouze zábava · 18+

## Hry
Zlatý automat · Blackjack · Ruleta · Kostka · Hod mincí · Crash · Mines · Plinko · Hi-Lo · Kolo štěstí (zdarma každou hodinu)

## Funkce
- Registrace a přihlášení (data se ukládají lokálně v `localStorage`)
- Start 5 000 žetonů, levely a XP
- Tracker statistik a graf vývoje zůstatku
- Profil: avatar, banner, status, bio, tituly, odznaky
- Obchod s kosmetikou (rámečky, jména, bannery)
- Vlastní motivy a barvy
